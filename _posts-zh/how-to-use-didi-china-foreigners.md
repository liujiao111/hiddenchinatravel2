你刚从中国火车站出来，拖着行李箱。地铁标识都是中文，出租车司机已经在问你去哪，而Uber在这里用不了。

**滴滴（DiDi）是当地人用的打车App**——中国主要的网约车服务。对大多数首次来华的旅客来说，当地铁让人头疼、或者你累了不想讨价还价时，它是最方便的点对点出行选择。本篇是我们的[中国交通指南](/transport-in-china)系列之一。

![中国城市街道上的滴滴网约车——外国人在中国如何使用滴滴](/assets/blog/how-to-use-didi-china-foreigners/didi-ride-hailing-car-china-foreigners.webp "中国的滴滴网约车")

## 快速回答

你通常可以用一个**能接收短信的外国手机号**、**支付宝或微信支付**（通常已绑定国际信用卡）和**移动数据**来叫车。使用**滴滴App**，在**支付宝或微信**中打开滴滴小程序，或通过**高德地图（高德地图）**打车——无论哪种方式，操作习惯都一样：确认目的地名称、上车前核对车牌、行程结束后在App内支付。

支付还没准备好？先看这里 → [中国支付指南](/digital-survival-china-payment-guide)。

## 叫车前必须准备好的三样东西

三样东西——缺了任何一样，第一次从机场打车或深夜叫车都会变得很麻烦。

### 1. 能接收短信的手机号

滴滴（以及大多数打车App）需要一个能接收验证码的手机号。**不一定**要是中国号码——很多旅客用自己国家的手机号注册。不行的是只能上网、无法接收短信的eSIM。

### 2. 在中国能用的支付方式

至少准备好一种可用的支付方式：支付宝、微信支付，或App提供的银行卡/钱包。国际Visa/Mastercard绑定后通常可以使用，但取决于你的发卡行。

 [中国支付指南](/digital-survival-china-payment-guide)

### 3. 网络 / 数据

叫车、追踪行程和聊天都需要网络连接。你可以在酒店Wi-Fi下安装滴滴或高德——但乘车时请保持移动数据开启。

 [中国SIM卡/eSIM指南](/china-sim-card-for-foreigners)

## 叫车方式：滴滴App、小程序、或高德

你不需要安装所有App。选你已经有可用方案的那个就行。

### 方式A — 滴滴App

1. 从App Store / Google Play下载官方**DiDi** App。
2. 如果看到语言选项，切换为英文（或在安装后进入设置修改）。
3. 用一个能接收短信的手机号注册。
4. 完成App要求的个人资料验证。

### 方式B — 支付宝小程序

1. 打开已通过验证且绑定可用银行卡的支付宝。
2. 搜索**DiDi**或点击打车/出租车图标。
3. 打开小程序，确认可以发起订单。
4. 在需要叫车*之前*，先确认支付宝内的支付功能正常。

### 方式C — 微信小程序

如果你的微信已经设置好了：

1. 打开微信→搜索**滴滴** / **DiDi**（或在小程序/服务中找到）。
2. 打开滴滴小程序，按提示允许位置权限。
3. 确认**微信支付**已绑定且可以支付后再叫车。

适合不想多装一个App的情况——前提是微信支付在你的账号上确实能用。

### 方式D — 高德地图（高德地图）打车

如果你已经在用**高德地图**导航，也可以直接在上面叫车——找到打车/网约车标签页（打车）。你同样会看到车牌、车型和App内支付；叫车流程和滴滴类似。

高德地图对中文地址和上车点定位通常更好用，所以有些旅客先在高德上搜索目的地，然后从那个位置点打车。更多关于高德的设置 → [中国地图与导航](/google-maps-china-not-working)。

**先用哪个？**

- 支付宝或微信已经能用 → 小程序就可以
- 想要最清晰的英文界面和行程记录 → 滴滴App
- 本来就一直用高德 → 高德打车很方便

不同入口的价格和可选车型可能略有差异——确认前请查看预估价。

## 一个实际案例

假设你在**大理**，需要打车去**大理古城**。

1. 站在一个明确的上车点（或App建议的滴滴上车点）。
2. 点击**Where to?**，输入英文名或粘贴中文地址——然后选择匹配的结果，如果有门选项（南门、北门等），选对你要走的**入口**（南门通常是人最多的那个）。
3. 选择**Economy**（经济型），查看一口价/预估费用，点击确认。
4. 车到达后，核对**车牌+颜色+品牌**与屏幕显示一致。如果有陌生司机没有订单就招呼你上车，不要理会。
5. 上车后，App可能会要求你提供手机号的**后四位**——只出示后四位即可。
6. 到达后，在App内支付。不需要现金讨价还价。

这就是完整流程。下面的截图标注了同样的步骤。

## 逐步操作：叫车并核对司机

### 搜索正确的目的地

在地图上确认你的上车点，然后设置目的地。

![步骤1截图——滴滴首页，Where to搜索栏已高亮](/assets/blog/how-to-use-didi-china-foreigners/step-01-where-to.webp "步骤1：点击Where to?")

1. 点击**Where to?**，输入英文（例如"Bell Tower"）或粘贴中文地址。
2. 同时查看结果中的**英文名和中文地址**。
3. 选择与你计划一致的结果——酒店、景区入口或地铁出口，而不是一个名字相似的居民小区。如果有门选项（南门、北门等），选择与你计划一致的入口。
4. 可选：保存常用地点。

![步骤2截图——滴滴搜索大理古城的结果，匹配的地点已高亮](/assets/blog/how-to-use-didi-china-foreigners/step-02-search-results.webp "步骤2：选择正确的目的地")

**实用提示：** 大地标用英文搜索即可。酒店和餐厅，请将确认信息中的**中文地址**粘贴到滴滴（或先粘贴到高德）中。靠猜拼音拼写是人们走错门的常见原因。更多地图使用技巧 → [中国地图与导航](/google-maps-china-not-working)。

在繁忙的车站和机场，当App出现建议的**上车点**时请使用它——司机会在那些位置找你。

### 选择车型并等待司机

1. 选择车型（Economy经济型是日常默认选项）。
2. 确认前查看**一口价**或**预估价**。
3. 点击**Confirm**叫车。

![步骤3截图——滴滴车型列表和确认按钮已高亮](/assets/blog/how-to-use-didi-china-foreigners/step-03-confirm-ride.webp "步骤3：选择车型并确认")

4. 滴滴匹配中时会显示**Finding a driver**。需要时可以**Cancel Trip**取消，或添加更多车型以加快接单。

![步骤4截图——滴滴正在寻找司机页面，Cancel Trip已高亮](/assets/blog/how-to-use-didi-china-foreigners/step-04-finding-driver.webp "步骤4：寻找司机中")

5. 司机接单后，仔细阅读屏幕信息：**车牌号**、车辆颜色、品牌、司机信息。
6. 追踪车辆位置。使用**Message**消息功能（通常自动翻译）发送"I'm at Exit B"（我在B出口）。如果你不会说中文或外国号码接不了本地电话，打电话比较困难——聊天功能通常就够了。

![步骤5截图——司机正在赶来，车牌号和Message按钮已高亮](/assets/blog/how-to-use-didi-china-foreigners/step-05-driver-on-the-way.webp "步骤5：核对车牌，必要时发消息")

**车牌和车型匹配之前不要上车。** 无视路边没有订单就问"taxi?"的拉客者——那些是无营运资质的黑车。

### 上车后：核验并保持方向感

1. 如果App要求，向司机出示你手机号的**后四位**——不是完整号码。
2. 开门时再次确认车牌和车型。
3. 关注实时路线、距离和预计到达时间。
4. 注意**Safety Center**（安全中心）在屏幕上的位置——感觉不对时一键求助。
5. 如果有人在等你，使用**Share**分享行程。坐在后排并系好安全带。

下单后通常有一段免费取消时间——App会显示截止时刻。如果司机迟迟不动或长时间没有移动，取消后重新叫一辆车。

## 费用、收据和支付方式

行程结束后：

1. 打开行程摘要。查看上车点、下车点、时间和总费用。
2. 查看屏幕上显示的费用——这就是你要付的金额。如需详情，点击**Fare Breakdown**查看明细。
3. 点击**Pay**并选择一种可用的支付方式（滴滴钱包选项、微信支付或支付宝，取决于你的叫车方式）。

如果总额看起来不对，先不要支付，与司机或App内客服核实。行程记录中会保存收据。

有些银行卡会先在你的账户上临时冻结一笔金额，之后再结算最终费用。看起来偏高的待处理费用通常会回落到实际总额——不必慌张，与行程收据对比一下即可。

支付设置失败？→ [支付宝/微信验证故障排除](/alipay-wechat-pay-verification-failed)

## 常见问题和小提示

**我的订单失败了或价格看起来不对。**  
先检查网络、GPS和支付方式。到户外重试，或切换车型。

**司机取消了或一直不动。**  
取消后重新叫一辆车。如果感觉不安全，使用安全中心。

**我看不懂中文弹窗。**  
截图翻译，或给司机看请其帮忙理解那个页面。

**地图显示我在错误的位置。**  
到开阔处，刷新GPS，或将上车点设为附近的地标。

**没有中国手机号——怎么联系司机？**  
使用App内消息（自动翻译）。"I'm at Exit B / north gate"（我在B出口/北门）大多数时候就够了。

**可以让司机等我然后再送我回去吗？**  
有时可以——可能需要等待费。离车前在聊天中谈好，或者干脆叫两单。

**一定要装滴滴App吗？**  
不一定。支付宝或微信里的滴滴小程序对很多旅客来说就够用了，如果你已经用高德导航，**高德打车**也是不错的替代方案。规则不变：上车前核对车牌。

**始终记住：** 上车前核对车牌和司机 · 坐后排 · 系安全带 · 感觉不对时使用安全中心或拨打当地紧急电话。
