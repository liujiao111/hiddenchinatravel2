对大多数游客来说：在机场或市区官方门店买一张中国联通预付费SIM卡，带好护照原件，做好人脸扫描的心理准备。

但在做任何事之前，你需要做一个决定——实体SIM卡还是eSIM——因为它们解决不同的问题。这就是本指南要讲的。

这三个担忧都合理，而网上那些矛盾的建议确实没什么帮助。简短回答：外国人可以在中国买到SIM卡，但流程与大多数国家不同，为你的行程选错方案会带来实实在在的麻烦。

## 实体SIM卡 vs eSIM：到底哪个适合你

这是大多数指南要么过度简化要么自相矛盾的地方，所以我们直说。

两者都能在中国上网。区别在于：中国运营商的实体SIM卡给你一个**中国本地手机号**，而国际eSIM不给。这个区别比大多数人意识到的更重要。

| | **实体SIM卡（中国联通 / 移动）** | **国际eSIM（Airalo / Holafly / Nomad）** |
| --- | --- | --- |
| **在哪里买** | 机场柜台或市区门店 | 在线购买，出发前 |
| **需要护照和人脸扫描** | 是 | 通常不需要 |
| **有中国手机号** | ✅ 是 | ❌ 没有 |
| **能接收短信验证码** | ✅ 是 | ❌ 不能 |
| **绕过防火墙** | ❌ 不行——需要VPN | ✅ 可以——通过中国以外路由 |
| **设置难度** | 在店里20–30分钟 | 扫二维码 |
| **费用** | ¥50–100/月 | $5–30含1–15GB |
| **最适合** | 停留2周以上、微信支付设置（尤其是从零开始的新用户）、本地App注册 | 短期访问、仅需上网浏览 |

关键权衡：国际eSIM无需VPN即可绕过防火墙，这确实有用。但它不给你中国号码，意味着你无法用本地号码注册微信，无法使用美团（外卖、充电宝），还可能在某些预订平台上碰壁。对大多数2025–2026年的短期游客来说，**这比以前影响小了**——微信支付和支付宝现在支持外卡，滴滴也不需要本地号码。但如果你要从零设置任何账号，本地号码仍然更顺畅。

**实际中，大多数人是这样决定的：**

  * **2周以内，主要是地图和浏览** → 出发前买旅行eSIM，落地就有流量。[对比具体eSIM方案](/best-esim-for-china-travel#esim-plan-picker)，或阅读[Trip.com中国eSIM评测](/trip-com-esim-china-review)如果你在考虑这家。不用排队，不用人脸扫描。
  * **2周以上，或想用微信支付 / 本地App短信** → 实体SIM卡。在店里花30分钟，但你会庆幸自己做了。
  * **去中国西部（西藏、新疆、四川偏远地区）** → 特别推荐中国电信，在西部覆盖最强。
  * **今晚就到，没买eSIM** → 去运营商官方门店或机场柜台（见下文）。不要等商场的自助终端。

**外国人能在中国买SIM卡吗？**

可以——外国人可以凭护照在中国合法购买SIM卡。但你必须在运营商官方门店完成实名登记和人脸验证。我会一步一步带你走完选择、购买和设置的整个过程。

## 选哪家运营商？联通、移动还是电信

三个选项，选择比看起来简单。

**中国联通**是外国人用自己的手机的标准选择。它使用GSM/WCDMA/LTE频段，与大多数在中国以外购买的手机兼容，套餐价格有竞争力，较大的门店更习惯处理外国护照。¥69可获得10GB流量和500分钟国内通话，有效期30天——其全国流量王套餐是可靠的默认选择。

**中国移动**覆盖最广——在农村地区信号最强，4G/5G覆盖面最大（城市5G现在已将大多数国际手机的2G回落降到最低）。问题是其旧有3G基础设施使用非标准频段，大多数国际手机不支持。在4G/5G覆盖区域这不影响，但在较小城镇你的手机可能降速到极慢的2G。城市为主的旅行选择它没问题；但如果你要去偏远地区，需注意频段问题。

**中国电信**在西部地区的覆盖比另外两家都好。如果你的行程包括西藏、新疆或四川偏远地区，这确实是更好的选择。城市旅行的话，相比联通没有明显优势。

**一句话规则：** 在城市→中国联通。去西部→中国电信。

## 为什么中国SIM卡的办理流程不同

如果你在东南亚或欧洲买过预付费SIM卡，你习惯了交钱就走人。中国不是这样的。

自2019年12月起，中国销售的每张SIM卡必须实名登记，验证包括**生物识别人脸识别**——将你的实时面部与护照照片实时比对。这适用于所有人，包括外国游客。实际后果是：你不能在街边小店买到SIM卡。你需要去运营商官方门店或机场柜台，并带好护照原件。

还有一点值得了解：在中国的App生态中，你的手机号充当身份证明。当微信或支付宝要求你用中国号码验证时，它们不仅仅是在确认联系方式——它们把那张已登记的SIM卡作为一种身份证件。外国号码通常无法通过这种验证，这就是为什么你的原SIM卡即使有信号也无法解锁本地服务。

## 完整流程：在中国购买SIM卡

### 出发前

**解锁手机。** 如果你是合约机购买的手机（在美国、英国和澳大利亚常见），可能被锁定到某个网络。出发前用别人的SIM卡测试一下。如果锁了，打电话给你的运营商要求解锁——大多数会免费解锁，尤其是合约到期后。

**检查手机的频段兼容性。** iPhone XR及以上和旗舰Android手机大多与中国网络广泛兼容。中端或较旧设备可能缺少关键频段。可以在[GSMArena](https://www.gsmarena.com/)或[frequencycheck.com](https://www.frequencycheck.com/)查询——输入你的具体型号对比中国联通或中国移动。

**如果你会用酒店Wi-Fi或中国本地SIM卡，在出发前安装VPN。** 因为在这些网络上Google、WhatsApp、Instagram和Gmail通常会失效。移动数据上的旅行eSIM通常不需要VPN。VPN应用在中国App Store和Google Play上已被下架，所以如果需要，请在入境前安装。我用[NordVPN](/go/nordvpn)。ExpressVPN更简单；我还没有把它作为日常中国VPN使用过。在[中国最佳VPN](/best-vpn-for-china)中挑选。

**决定在哪里买SIM卡：**

  * **机场柜台** — 方便，有英语工作人员，流程快**（很多现在支持二维码+护照OCR自助服务）。套餐比市区门店贵20–30%，选择有限。适合落地后想零麻烦的人。
  * **市区运营商官方门店** — 性价比更好，套餐选择更多，处理特殊情况更可靠。去直营营业厅，不要去小型加盟店。小店通常不能或不愿意处理外国护照。
  * **在线预订** — 有些服务可以送SIM卡到酒店或通过上传护照照片远程激活。适合想在落地前一切都搞定的人。

### 在门店：实际流程

走进去说：**"我要办手机卡"（Wǒ yào bàn shǒujī kǎ）——"I'd like to buy a SIM card."**

流程如下：

  1. **他们会要你的护照。** 只接受原件——复印件不行。他们会扫描护照照片页。
  2. **人脸扫描。** 你坐在摄像头前或举起手机对着摄像头。系统将你的实时面部与护照照片比对。通常需要10–30秒。
  3. **选择套餐。** 工作人员会在屏幕或塑封卡片上展示选项。游客可关注¥50–100范围的短期预付费方案，包含10GB+流量和30天有效期。
  4. **付款。** 现金（人民币）、微信支付或支付宝。信用卡很少被接受。
  5. **激活。** 需要几分钟。在确认能用之前不要离开——见下面的清单。

出发前需知道的一点：**小店可能会拒绝你**。这不是普遍现象，但加盟店或旅游区以外的小店有时会告诉外国人他们无法处理外国护照。他们通常其实可以——只是没办过。去旗舰店或直营店（有完整运营商标识、没有混入其他业务的那些）是可靠的选择。

### 离开前：检查清单

不要在确认以下全部之前离开门店：

  * SIM卡已插入，手机有信号
  * 设置中移动数据已开启
  * 能打开网页（试baidu.com——避免防火墙问题）
  * 能发送和接收测试短信
  * 你的中国号码已写下或拍照
  * 知道如何充值（让工作人员演示运营商App或微信小程序）

短信测试是大家最容易跳过然后后悔的。在柜台上花60秒能省去之后很多麻烦。

## 总结

在中国办SIM卡比大多数国家步骤多，但一旦知道预期是什么，其实很简单。让人措手不及的是：需要护照原件（不是复印件）、人脸扫描，以及偶尔有门店说帮不了你——而几条街外的另一家分店可以。

如果你在实体SIM卡和eSIM之间犹豫，用这个作为最终决定标准：**这次行程你需要从零注册任何中国App吗？** 如果需要，买带本地号码的实体SIM卡。如果你已经有了账号，只需要流量和上网，国际eSIM确实是更简单的选择。
