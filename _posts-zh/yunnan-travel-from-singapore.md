## 新加坡公民需要中国签证吗？

**如果你持新加坡普通护照进行短期旅游度假，不需要签证。** 新中互免签证协议于2024年2月9日生效，允许旅游、商务和探亲等目的最长30天停留。涵盖云南和经昆明入境。更长的停留和就业或新闻等活动有不同要求。

| 入境问题 | 新加坡普通护照持有者的答案 |
| --- | --- |
| 短期云南度假签证 | 不需要 |
| 此协议下最长停留 | 每次入境30天 |
| 昆明入境和云南旅行 | 涵盖 |
| 更长停留或工作 | 出行前查询相应签证 |

这是一项**双边协议**，不同于中国的过境免签规则。简单的新加坡—云南往返度假不需要安排第三国过境行程。入境政策可能变化，出发前请查看[新加坡外交部旅行页面](https://www.mfa.gov.sg/Countries-Regions/C/China/Travel-Page)和你的航空公司的证件要求。

**住在新加坡但持其他护照出行？** 规则取决于你的国籍和护照，而非出发地。在[中国签证查询器](/china-visa-checker)中输入你的护照、停留时长和路线，然后与相关中国大使馆确认结果。[中国签证指南](/do-i-need-a-visa-for-china)更详细地解释了入境选择。

## 如何从新加坡到云南

**昆明长水国际机场（KMG）**是首先查看的机场。新加坡（SIN）到昆明可能有直飞，飞行时间约四小时。航班时刻表、航空公司和票价会变，因此在确定酒店住宿夜之前请双向比较。

大理（DLU）和丽江（LJG）预计需要比较中转航班。短中转在搜索结果中可能看起来有吸引力，但入境、行李和航站楼转换可能让整天长很多。

| 到达机场 | 如何适合首次旅行 | 预订前请核实 |
| --- | --- | --- |
| **昆明（KMG）** | 昆明→大理→沙溪→丽江的天然起点 | 直飞可用性和到达时间 |
| **大理（DLU）** | 如果你计划跳过昆明则有用 | 中转时长和后续交通 |
| **丽江（LJG）** | 更适合仅滇西北行程或返程航班 | 中转和返程票价 |

**我的建议：** 飞到昆明。对于返程航班，比较两个选择：丽江→新加坡中转，或回到昆明再飞。前者省去走回头路；后者在你的日期上可能更简单或更便宜。比较*整体*旅程而非仅航班价格。

## 在云南应该待多少天？

算上到达和出发日。一个宣传为**云南六天**的路线不自动包含从新加坡的航班、开始前一晚住宿或返程旅程。

| 从新加坡出发的总自然日 | 可行方案 |
| --- | --- |
| **5-6** | 选两个驻点；沙溪或丽江留到下次 |
| **7** | 专注昆明、大理和丽江，或沙溪仅一晚且接送已安排 |
| **8-9** | 昆明、大理、沙溪过夜和丽江，节奏更舒适 |
| **10+** | 进一步放慢或核实接送时间后考虑另一个停留点 |

### 应该加香格里拉吗？

对于一周行程，我会跳过。香格里拉海拔超过3000米，增加了旅行时间和海拔适应。十天或以上时更可行，尤其是你愿意在其他地方削减时间或预订不同的返程路线。

## 从新加坡去云南值得吗？

如果你想要山间空气、湖边村庄、古城和更慢的日子，而非又一次城市短途旅行，云南是合适的选择。昆明是门户；大理是你可以在洱海边度过一个上午的地方；沙溪值得在一日游旅客离开后留下来；丽江让你触及滇西北的山景。

## 从新加坡出发的8天首次路线

**新加坡→昆明→大理→沙溪→丽江→新加坡**是八天行程的合理形态。逐日大纲是规划示例，不是航班或火车时刻表。

| 天 | 计划 |
| --- | --- |
| **1** | 飞到昆明；住一晚，晚上自由 |
| **2** | 从昆明到大理；在古城或洱海附近安顿 |
| **3** | 给大理一整天：洱海、村庄或古城 |
| **4** | 公路前往沙溪；住一晚 |
| **5** | 享受更慢的沙溪上午，然后继续前往丽江 |
| **6-7** | 探索丽江及周边，不再换酒店 |
| **8** | 经合适中转飞回家，或如果票务要求则提前返回昆明 |
