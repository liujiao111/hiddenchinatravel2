最快的办法是坐直达火车，大概1小时10分到1小时50分，站到站。速度不是唯一要考虑的事。虎跳峡在你的行程单上的话，包车能把一个普通的中转日，变成整趟云南行程里最值得记住的一天。

这段路还有一件事比选哪种交通工具更重要：香格里拉比丽江高了将近900米。怎么安排适应时间，会影响你抵达后的体验，很多攻略对这点一笔带过，但其实值得认真说清楚。

这篇文章把火车、公共汽车、直达包车、经虎跳峡的观光包车四种方式摆在一起比，你可以按自己的行程、行李量、还有想不想沿途看风景来选。

火车和大巴的时刻表会跟着季节、假期调整，确认自己实际出发日期的班次再订酒店和门票，别照搬别人游记里的截图当真。

如果还在安排前后几站，可以结合[丽江旅行指南](/lijiang-travel-guide)、[香格里拉旅行指南](/shangri-la-travel-guide)和[云南旅行指南](/china-destinations/yunnan)一起看。

## 四种方式一览

| 方式 | 大致用时 | 适合谁 | 主要限制 |
|---|---|---|---|
| 直达火车 | 约1小时10分–1小时50分 | 想快速、省心到达的人 | 不经过虎跳峡 |
| 公共汽车 | 约2.5–3.5小时 | 车站离酒店方便的人 | 不灵活，中途不能观光 |
| 直达包车 | 约3–4小时 | 带行李的家庭、团体 | 比火车大巴贵 |
| 经虎跳峡观光包车 | 约7–9小时 | 想顺路看虎跳峡的人 | 要花掉一整天 |
| 延伸路线（加哈巴/白水台） | 约8–10小时以上 | 摄影爱好者、回头客 | 行程很长，不是人人都适合 |

火车全程约140公里，1小时10分到1小时50分，二等座票价大约¥56–70，一等座约¥89–111。不少文章还在描述这段路是"4–5小时、山路弯道多、容易晕车"，这个说法从2021年9月香丽高速通车之后就已经不准了。现在大巴和包车走的基本都是高速，弯道多的路段主要集中在去虎跳峡的那段地方道路，不是丽江到香格里拉这段直达路线本身。

简单说：
- **只求快** → 坐火车。
- **车站离酒店正好方便** → 大巴也行。
- **带行李、想酒店到酒店** → 直达包车。
- **想顺路看虎跳峡** → 观光包车。

## 方式一：坐火车

![丽江站站房入口，丽江到香格里拉直达列车的出发车站](/assets/destinations/yunnan/lijiang-shangri-la/lijiang-railway-station-entrance.webp)

对只想从一个城市到另一个城市的人来说，火车是最稳妥的默认选项，比走公路快，价格合理，受公路堵车影响较小；不过，恶劣天气和运营调整仍可能影响列车。

丽香铁路2023年11月开通，现在每天有多班直达列车，用时在1小时10分到1小时50分之间，具体看车次。二等座大约¥56–70，一等座约¥89–111，这两个数字当参考就好，具体价格按车型和季节会有点浮动，建议订票前用实际出发日期再查一遍。

**怎么订票**：可以用中国铁路官方的[12306](/book-china-high-speed-rail-foreigners)，或者用[携程](/go/trip-trains)，也可以让酒店帮忙订。订票时姓名一定要和护照上完全一致，护照就是你的车票，上车也要带同一本护照。

**去车站怎么走**：丽江站在丽江古城外面，古城里很多路段是步行街，车进不去，司机没法开到酒店门口。出发前问问酒店最近的、车能停的接送点在哪，再留出20–50分钟的余量，具体看你从哪出发、路上堵不堵。到了香格里拉这边，车站离独克宗古城大概2–3公里，不算远，但最后一段还是取决于你酒店具体在哪。

![香格里拉独克宗古城附近的传统建筑与远处雪山](/assets/destinations/yunnan/lijiang-shangri-la/dukezong-old-town-shangri-la.webp)

**火车适合谁**：一个人出行、行李不多、就想快点到、不想折腾一整天在路上的人。如果你带着好几个大箱子、有小孩、或者有人行动不便，包车通常体验会好不少。

## 方式二：包车

包车比火车大巴都贵，但它能给你一样火车大巴给不了的东西：路线、节奏、沿途停哪儿，都是你说了算。

### 直达包车（约3–4小时）

这是最简单的版本，司机在丽江酒店附近一个能停车的地方接上你，一路基本走高速，直接送到香格里拉的酒店，行李全程在车上。适合：

- 带着好几个箱子的情侣或家庭
- 不想折腾车站、转车的年长旅客
- 同行亲友共同分摊包车费用的小团体
- 出发/到达时间正好跟火车班次对不上的人

算上去车站的接驳、等车、搬行李这些时间，火车的"快"其实没想象中那么明显，直达包车的总耗时跟火车算下来可能差不了太多。

![黑色七座商务车外观，可供包车车型参考](/assets/destinations/yunnan/lijiang-shangri-la/private-transfer-mpv-exterior.webp)

### 经虎跳峡的观光包车（约7–9小时）

对很多人来说，这才是选包车而不是火车的真正理由。常见路线是这样：

**丽江或束河的酒店 → 虎跳峡上段 → 午饭或中途休息 → 香格里拉的酒店**

虎跳峡上段是一天行程里最现实的选择，开车能到，能看到峡谷最壮观的那部分，又不用走很长的徒步路线。这跟中虎跳、高路线完全是两回事，那两个是真正的徒步路线，需要单独排一天、穿合适的鞋，有时候还要在当地住一晚。别指望把它们塞进一个中转日里。

门票价格和是否需要提前预约，建议出发前再确认一下，可以参考我们的[中国景区预约制度说明](/why-china-attractions-require-reservations)。

![虎跳峡上段的金沙江、峡壁与观景步道](/assets/destinations/yunnan/tiger-leaping.webp)

石鼓的长江第一湾也是可以考虑的观景点，但它需要绕行，不属于直达路线或通常的虎跳峡停靠点。如果想把它加进包车行程，询价时要单独说明，并为当天多留时间。

![丽江石鼓长江第一湾，金沙江环绕山谷转弯的景观](/assets/destinations/yunnan/lijiang-shangri-la/yangtze-first-bend-shigu.webp)

### 延伸路线：加哈巴、白水台（约8–10小时以上）

如果你有一整天时间：

**丽江 → 虎跳峡 → 哈巴村或观景台 → 白水台 → 香格里拉**

这条路线一天下来很长，适合摄影爱好者、来过云南不止一次的人、特别想看白水台的人。如果容易晕车、带着小孩、走路走不了太久、或者是冬天天黑得早，这条路线不太合适。独克宗古城、松赞林寺、纳帕海也别指望全塞进同一天，选一两个你最想看的，剩下的时间留给路上。

### 包车报价应该包含什么

| 一般包含 | 一般不包含（除非特别说明） |
|---|---|
| 车辆和司机 | 景点门票 |
| 约定的接送地点 | 餐饮 |
| 油费、过路费、常规停车费 | 住宿 |
| 约定的等待时间 | 专职英语向导 |
| 行李搬运 | 私人消费、临时加的行程、超时费用 |

订车前最好白纸黑字确认清楚：车型和实际能装多少行李、具体接送地点、计划停靠哪些地方、停多久、超时怎么算。比起到了当地才跟陌生司机现场扯皮，提前问清楚总归省心。

### 多少人该选什么车

| 人数 | 一般车型 | 需要确认的点 |
|---|---|---|
| 1–3人 | 轿车或紧凑型SUV | 实际能放几个大箱子 |
| 3–5人 | 7座商务车 | 人数+行李的实际配置，不是单看座位数 |

## 方式三：坐公共汽车

丽江到香格里拉的直达大巴通常走高速，但预订前仍要确认具体路线。可预留**约2.5到3.5小时**作为车程参考，遇到接客、交通或天气变化可能更久。近期售票页面上，部分直达班次显示**约¥60起**；价格和发车时间随日期、运营方变化，不能按“每半小时一班”安排后续行程。

适合选大巴的情况：
- 车站位置正好跟你的酒店顺路
- 行李不多
- 不需要中途观光
- 发车时间刚好比火车更合适

带着好几个箱子、有小孩需要安全座椅、或者想顺路看虎跳峡的话，大巴就不太合适了。大巴和火车的实际票价可能接近，比较时也要算上车站接驳费用。车站位置和时刻表会变，出发前最好跟酒店确认一下实际的上车点，别完全信网上一张旧时刻表。

## 按你的情况选

| 你的情况 | 推荐方式 |
|---|---|
| 一个人、行李不多 | 火车 |
| 就想尽快到 | 火车 |
| 想看虎跳峡 | 观光包车 |
| 带小孩 | 包车 |
| 年长旅客或行动不便 | 包车 |
| 箱子又多又大 | 包车或商务车 |
| 大巴站正好方便 | 公共汽车 |
| 还想加白水台 | 延伸观光路线 |
| 想走虎跳峡高路线徒步 | 单独安排徒步行程，别指望当天中转顺带走完 |

单纯图快、图省事，火车赢。想看风景、要灵活，包车的钱花得值。真正该想清楚的是：这一天你只想当成赶路的时间，还是也想让它算进这趟旅程里。

## 海拔：比选交通方式更值得花时间搞懂的事

丽江海拔大约2400米，香格里拉市区大约3200–3300米。无论坐火车还是包车，都需要考虑抵达后在更高海拔住宿的影响。

沿昆明 → 大理 → 丽江 → 香格里拉逐步旅行，可以为适应海拔留出时间，但关键是各地实际停留几晚；仅仅途经这些城市，不代表已经适应。坐几小时汽车，也不能代替适应所需的时间。

- 抵达后的前48小时避免饮酒和剧烈运动，先安排轻松活动。
- 正常补水，不要靠强迫自己大量喝水预防高反。
- 出现头痛、恶心、头晕等症状时，不要继续升高住宿海拔；如果休息后仍加重，应降低海拔并就医。
- 意识不清、静止时呼吸困难或走路不稳，应立即寻求医疗帮助，并尽快在他人协助下下降，不必等到某个固定海拔才就医。
- 带婴幼儿，或有心肺疾病、既往严重高反史时，出发前先与医生讨论高原安排。

可进一步阅读[美国疾控中心的高海拔旅行指导](https://www.cdc.gov/yellow-book/hcp/environmental-hazards-risks/high-altitude-travel-and-altitude-illness.html)。

## 天气、晕车和其他实用提醒

**天气**：山区天气变化快，哪怕从丽江出发那天挺暖和，也带件厚一点的外套，雨具和水随身带着，不分季节。

**晕车**：走高速的这一段路况很稳。如果选的是经虎跳峡的观光包车，去峡谷的那段地方道路确实弯道多。如果你对弯道敏感，火车或直达高速包车可以减少这类路段，但不能保证不会晕车。

**酒店接送**：丽江古城和独克宗古城都有不少步行街路段，所谓"酒店接送"很多时候其实是送到车能到达的最近一点。订车前把酒店的确切名称给我们，我们会提前确认实际接送点在哪。

**网络信号**：两边城区信号都没问题，中间路段会时断时续。出发前在丽江先把流量搞定，可以参考我们的[中国eSIM指南](/best-esim-for-china-travel)。

**到了之后怎么出行**：滴滴在两边市区覆盖得还行，一出市中心就明显变差。还没注册账号的话，看看我们的[外国人滴滴使用指南](/how-to-use-didi-china-foreigners)。
