# Hidden China Travel 2

Clean Next.js foundation for the next version of Hidden China Travel.

## Stack

- Next.js 16 with App Router
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint
- Vercel-ready deployment

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```text
src/app/                 Routes, layouts, metadata, and global styles
src/components/          Reusable UI components
src/lib/                 Shared configuration and utilities
src/types/               Shared TypeScript types
content/guides/          Practical China travel guides
content/destinations/    Destination and itinerary content
public/                  Static assets
```

## Product direction

1. Practical China travel guidance that builds trust.
2. Yunnan-first destination and experience content.
3. Enquiry-focused journey and private-tour product pages.

## Commands

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Deployment

The `main` branch is connected to Vercel for automatic deployments.
